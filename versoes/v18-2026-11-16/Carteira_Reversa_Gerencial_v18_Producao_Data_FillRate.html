1. Bases e reconhecimento automático

Clique em Importar bases direto do GitHub para buscar os arquivos públicos do repositório, ou carregue os arquivos Excel ou ZIP manualmente, com qualquer nome. O sistema identifica o papel de cada aba pelo conjunto de colunas e pela estrutura dos dados — pedido/pendente, CAD, Malha, Estoque Fábrica, Grade CD, DPAR e Produção. O nome da aba não define a função da base; nas grades, o título da aba é a referência para identificar o CDD. A leitura foi otimizada para bases grandes e as tabelas na tela são limitadas, sem limitar a exportação.

Adicionar bases de pedidos, estoque e apoio — com qualquer nome

Aceita planilhas .xlsx/.xls/.xlsm/.csv ou pastas .zip com essas planilhas, inclusive em subpastas. Leitura otimizada em segundo plano no próprio navegador quando suportada; é necessária internet para carregar os leitores Excel/ZIP nesta versão.

Nenhuma base carregada
Carregue os arquivos com pedidos/pendente e com estoque. Excel ou ZIP são aceitos independentemente do nome. O sistema identifica os papéis pelas colunas; as redes são extraídas apenas dos pedidos.

Como o reconhecimento funciona: o nome do arquivo/aba não é uma condição. Os campos estruturais precisam ser encontrados; se faltar um campo ou duas estruturas forem semelhantes, a aba fica para revisão, sem criar números fictícios.

Leitura v18: CAD: Código EG em Cod S4_2 (conforme coluna C informada), SAP em Cod_SAP, fator em Quantidade_prod_pallet. VD: SKU EG/PCA em Sku PCA (alternativa: Sku S4), origem Orig. S4, estoque-base D1 em PLT. Somente a Malha é consultada por SKU SAP. Grade CD: CodigoProduto = SKU EG sem o último dígito, SaldoDisponivel em CX; centro identificado pelo nome da aba (ex.: São José = 966-CD / BRD2). Produção COD_PROD em EG/PCA; ORIGEM é o nome da origem, convertido internamente para o mesmo centro da Malha; PRODUÇÃO representa a data prevista e ESTOQUE é campo distinto. A previsão não é volume e não amplia cobertura.

Origem VD ≠ Origem CD

VD — abastecimento via fábrica
Pedido → CAD (EG/SAP + fator) → Malha (SKU SAP + Destino Comercial) → fábrica autorizada → estoque em pallets → caixas equivalentes. Produção é uma data prevista e é informada separadamente.
CD — abastecimento via CDD
Pedido → Loja/EG → DPAR Shibata / cadastro → CDD responsável → grade do mesmo CDD em caixas. Não somar ou substituir por estoque de VD.
